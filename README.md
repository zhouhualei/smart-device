# 森居蓝牙管家

双击 `森居蓝牙管家.app` 可以直接运行桌面客户端。

如果 macOS 第一次提示安全确认，也可以双击 `打开森居蓝牙管家.command` 运行同一个客户端。

## 真实连接能力

- 点击蓝牙扫描按钮，会调用 macOS/Electron 的真实 BLE 扫描能力。
- 选择附近设备后，应用会尝试建立 GATT 连接。
- 如果设备提供标准电量服务，应用会读取真实电量。
- WiFi 配网不是通用协议，需要设备厂商提供 BLE 服务 UUID 和写入特征 UUID。填入后，应用会把 `{ ssid, password }` 写入对应特征。

很多智能家居设备只允许自家 App 或网关接入；如果不知道厂商的配网 UUID，应用只能发现和连接 BLE，不能凭空完成 WiFi 联网。

## 开发运行

如果要从命令行运行：

```bash
npm install
npm start
```

项目内已经安装了本地 Node 和 Electron，不依赖系统里的旧 Node。
